# Default half degree cells reference data, including geometry and bioclimate measurements, for demonstrational purposes

This function returns a data frame with reference data

## Usage

``` r
default_hcaf(.clim_vars = default_clim_vars())
```

## Arguments

- .clim_vars:

  vector of bioclimate variables to use

## Examples

``` r
if (FALSE) { # \dontrun{
hcaf <- default_hcaf()
} # }
```
