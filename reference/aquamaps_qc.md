# Quarter degree cell metadata (only identifiers and coordinates)

A dataset containing metadata such as identifiers and bbox coords

## Usage

``` r
aquamaps_qc
```

## Format

A data frame

- OBJECTID:

  OBJECTID

- Quadrant:

  Quadrant

- Global_Quadrant:

  Global_Quadrant

- c_square_code:

  c_square_code

- N_limit:

  N_limit

- E_limit:

  E_limit

- S_limit:

  S_limit

- W_limit:

  W_limit

- area\_\_km2\_:

  area\_\_km2\_

- centrelatitude:

  centrelatitude

- centrelongitude:

  centrelongitude

- Northern:

  Northern

- Southern:

  Southern

- Eastern:

  Eastern

- Western:

  Western

- Area:

  Area

- CenterLat:

  CenterLat

- CenterLon:

  CenterLon

- Shape:

  Shape
