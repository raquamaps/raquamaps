# Half degree cell authority file for EU with bioclimate data (8,493 cells)

A dataset containing reference data for bioclimate variables

## Usage

``` r
aquamaps_hcaf_eu
```

## Format

A data frame \[8,593 x 12\]

- CsquareCod:

  CsquareCod

- LOICZID:

  LOICZID

- Elevation:

  Elevation

- TempMonthM:

  TempMonthM

- PrecipAnMe:

  PrecipAnMe

- SoilpH:

  SoilpH

- SoilMoistu:

  SoilMoistu

- SoilCarbon:

  SoilCarbon

- CTI_Max:

  CTI_Max

- NPP:

  NPP

- Islands:

  Islands

- Basins:

  Basins

<https://www.aquamaps.org/>
