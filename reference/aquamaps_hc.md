# Half degree cell metadata (only identifiers and coordinates)

A dataset containing metadata such as identifiers (CsquareCod, LOICZID)
and bbox coords

## Usage

``` r
aquamaps_hc
```

## Format

A data frame \[8,593 x 12\]

- CsquareCod:

  CsquareCod

- LOICZID:

  LOICZID

- NLimit:

  NLimit

- Slimit:

  Slimit

- WLimit:

  WLimit

- ELimit:

  ELimit

- CenterLat:

  CenterLat

- CenterLong:

  CenterLong
