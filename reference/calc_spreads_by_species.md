# Retrieve environmental data and determine spread for a given species, using the bundled reference data

Retrieve environmental data and determine spread for a given species,
using the bundled reference data

## Usage

``` r
calc_spreads_by_species(.latinname)
```

## Arguments

- .latinname:

  character string with latin name for species

## Examples

``` r
if (FALSE) { # \dontrun{
spread_default <- calc_spreads_by_species(default_species())
} # }
```
