# Function to calculate probabilities

Function to calculate probabilities

## Usage

``` r
calc_probs(hcaf_species, spreads)
```

## Arguments

- hcaf_species:

  data frame with half degree cell parameter values for relevant
  bioclimate variables

- spreads:

  data frame with environmental envelope information (spreads for
  relevant bioclimate variables)

## Examples

``` r
if (FALSE) { # \dontrun{
p <- calc_probs(hcaf_by_species(), spreads)
} # }
```
