# Converts a raster grid into a dataframe of closed polygons which can be plotted with ggplot

Converts a raster grid into a dataframe of closed polygons which can be
plotted with ggplot

## Usage

``` r
r2df_polygons(r)
```

## Arguments

- r:

  a terra SpatRaster

## Value

a data frame with columns long, lat, group, bin
