# Half degree cell authority file for the world (259,200 cells) with bioclimate data

A dataset containing reference data for bioclimate variables

## Usage

``` r
aquamaps_hcaf_world
```

## Format

A data frame \[259,200 x 16\]

- LOICZID:

  LOICZID

- FAO:

  FAO

- CountryMain:

  CountryMain

- CountrySecond:

  CountrySecond

- CountryThird:

  CountryThird

- CsquareCod:

  CsquareCod

- Islands:

  Islands

- Basins:

  Basins

- SoilpH:

  SoilpH

- SoilCarbon:

  SoilCarbon

- CTI_Max:

  CTI_Max

- Elevation:

  Elevation

- TempMonthM:

  TempMonthM

- NPP:

  NPP

- SoilMoistu:

  SoilMoistu

- PrecipAnMe:

  PrecipAnMe
