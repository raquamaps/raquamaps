# Example grid cell data for various species of a certain category with presence in a basin (approx 410 000 rows)

A dataset that should be possible to get via rgbif, would be nice to
show that instead?

## Usage

``` r
aquamaps_presence_basins
```

## Format

A data frame \[410,288 x 5\]

- loiczid:

  loiczid is the unique cell identifier

- csquarecode:

  csquarecode is also a cell identifier

- lname:

  lname is the latin name for a species

- category:

  category is a category for a species

- inbassin:

  inbassin states whether the presence is in a basin
