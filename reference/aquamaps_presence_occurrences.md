# Example grid cell data for various species (approx 40 000 rows)

A dataset that should be possible to get from rgbif, should show how to
do it.

## Usage

``` r
aquamaps_presence_occurrences
```

## Format

A data frame \[39,307 x 4\]

- loiczid:

  loiczid

- csquarecode:

  csquarecode

- lname:

  lname

- occurrence:

  occurrence

## Source

<https://www.aquamaps.org/>
